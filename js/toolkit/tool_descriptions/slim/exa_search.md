Semantic web search via Exa: describe what you want in a full sentence and it
finds pages by meaning, each with a slice of page text. Best when you know what
you mean but not what it is called.
{{#if serper_search}}
`serper_search` is for exact strings, names, and error messages.
{{/if}}
{{#if tavily_search}}
`tavily_search` is for research questions that want a synthesized answer.
{{/if}}
{{#if docs_search}}
`docs_search` is for library documentation.
{{/if}}
