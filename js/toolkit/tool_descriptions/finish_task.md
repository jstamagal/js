Mark a task on the board done and say what came of it: where the work is, a
branch and commit, a finding, a path. Everyone on the bus gets a `done`
message with the number and the title, so whoever was waiting on it wakes.
The task's hold is released.

Finish only what is actually done and checked. If you are giving a task up
instead, let the hold expire or say so with `send`.
