# js generate — candidate flags. One option per line.

# Freebies and necessities — operations
--t2i                         Generate an image from text.
--i2i                         Edit or vary an input image.
--inpaint                     Regenerate a masked image region.
--outpaint                    Generate beyond the original image edges.
--upscale                     Enlarge an image with an upscaling model.
--variation                   Generate alternatives to a reference.
--t2v                         Generate video from text.
--i2v                         Animate a still or interpolate between anchors.
--r2v                         Generate video from subject or style references.
--v2v                         Transform a source video.
--extend-video                Continue an existing clip.
--tts                         Speak the supplied text.
--speech-to-speech            Convert a spoken performance.
--music                       Generate music.
--sfx                         Generate a sound effect or ambience.
--audio-to-video              Drive video from a speech or music track.

# Freebies and necessities — invocation and request
-m, --model ID                Override the operation's configured model.
-u, --url URL                 Send the request to this endpoint.
--home DIR                    Use this js profile.
--preset NAME                 Load a named js configuration preset.
--extra KEY=VALUE             Override a registered js setting for this run.
-p, --prompt TEXT             Supply prompt text or use - for stdin.
--prompt-file FILE            Read the prompt verbatim from a file.
--negative-prompt TEXT        Describe what to avoid.
--negative-prompt-file FILE   Read negative conditioning from a file.
--param KEY=VALUE             Pass an extra endpoint parameter; repeatable.
--param-json KEY=JSON         Pass an explicitly typed object, array, number or boolean.
--request-file FILE           Read a complete request body from JSON.
--model-revision ID           Request a particular model revision.
--endpoint-path PATH          Override the operation's HTTP route.
-n, --count N                 Request N outputs.
-s, --seed N                  Set the random seed.
--size WxH                    Set output dimensions in pixels.
--width PX                    Set width independently.
--height PX                   Set height independently.
--aspect-ratio W:H            Set the proportions of the output.
--resolution NAME             Select a model-defined tier such as 720p.
--quality LEVEL               Select a model-defined quality tier.
--duration SEC                Set the generated audio or video length.
--format NAME                 Request an output format such as png, webp, wav or mp4.
